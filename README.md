# BestWars

BestWars is an experimental project built around pairwise comparisons and rating systems.

The idea is simple: instead of asking people to rate items directly, show them two options and let them choose the one they prefer. Over time, these comparisons produce a ranked list of items.

## Current version

The project currently consists of a console-based prototype written in Python.

It implements:
- Pairwise item comparisons.
- Elo-based rating calculations.
- Automatic selection of pairs for comparison.
- Saving and displaying rating results.

The rating system is still experimental and may evolve as the project develops.

## What's next

This is the first working prototype. The project may eventually grow into a platform for comparing things across different categories and exploring collective preferences.

For now, the focus is on experimenting with the core idea and developing it further.
